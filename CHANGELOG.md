# Roster changelog

## 0.1.0 (1) — 2026-11-11

The first release of Roster: a Mac companion that lists your Git projects and worktrees with the Claude Code, Claude Desktop, and Codex sessions that belong to them, and opens each one in its own app.

### New

- See every project, worktree, and agent session on your Mac in one window, with branch, local changes, size on disk, and recent activity.
- Open a session in Claude Desktop, Claude Code, or Codex, or start a new one in a worktree.
- Read a session's full transcript in Roster and find text in it with ⌘F.
- Search session names, and opt in to full-text and semantic search of conversations. The search index stays in memory and is cleared when you quit.
- Find sessions outside your projects in Other Sessions (⇧⌘F).
- Review worktrees in Cleanup and remove the ones you no longer need, with a confirmation showing local changes and unpushed commits, Undo where nothing was lost, and an option to delete leftover branches.
- Turn on Session Sharing to let Claude Code and Codex read your past sessions through a local MCP server. It's off by default.
- Link sessions so agents can message each other through Roster. Agents can ask to link, and you approve each request.
- Roster checks for updates and installs them for you. You can turn this off in Settings.
